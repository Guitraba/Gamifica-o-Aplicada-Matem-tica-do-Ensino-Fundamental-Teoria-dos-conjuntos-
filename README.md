#Projeto de extensão
Este projeto tem como objetivo criar uma atividade gamificada sobre Teoria dos Conjuntos para alunos do Ensino Fundamental. Utilizando a plataforma Wordwall, serão desenvolvidos desafios interativos que auxiliem na compreensão dos conceitos matemáticos, promovendo aprendizado dinâmico, engajamento e raciocínio lógico.
