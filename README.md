# Desafio da Teoria dos Conjuntos 🎮

Projeto de Extensão desenvolvido para a disciplina de Fundamentos Matemáticos 
para a Ciência da Computação.

## 📋 Descrição

Jogo educativo interativo criado no Wordwall com questões de múltipla escolha 
sobre Teoria dos Conjuntos, divididas em três níveis de dificuldade: 
Fácil, Médio e Difícil.

## 🎯 Objetivo

Fixar os conceitos de Teoria dos Conjuntos de forma dinâmica e gamificada,
permitindo que os alunos testem seus conhecimentos em diferentes níveis.

## 📚 Conteúdo

### Nível Fácil
* Notação de conjuntos
* Símbolo de pertinência (∈)
* Conjunto vazio (∅)
* Subconjuntos

### Nível Médio
* União (∪) e Interseção (∩)
* Diferença entre conjuntos (–)
* Relação de subconjunto (⊂)
* Conjuntos disjuntos

### Nível Difícil
* Conjunto das partes P(A)
* Conjuntos numéricos (ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ)
* Lei de De Morgan
* Números irracionais
